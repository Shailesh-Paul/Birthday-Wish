SANDHU BIRTHDAY WEBSITE V3
Open index.html in a browser.

Cake sequence:
- Tap Cut the cake.
- Cake/knife animation + confetti.
- Synthesized traditional Happy Birthday melody starts after click.
- Celebration lasts 30 seconds.
- Music stops and personalized note animates into view.

Music is generated with Web Audio, so no external music file is needed. It starts only after a user interaction due browser autoplay rules. Pause/play control is included.

Gallery:
- Add multiple photos, remove photos, captions, lightbox, slideshow.
- Local selected photos are not uploaded. To share photo gallery through a public link, include image files in a folder and update paths before publishing.
